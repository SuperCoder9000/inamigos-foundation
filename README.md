# InAmigos Foundation — Awareness Webpage

A static awareness webpage created for InAmigos Foundation as part of a web development internship task.

## 🌿 About the Project
This webpage spreads awareness about InAmigos Foundation's NGO projects and initiatives including Project SEVA, BACHPANSHALA, UDAAN, PRAKRITI, JEEV, and VIKAS.
